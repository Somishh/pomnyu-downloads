# Помню

Личный органайзер на русском языке для Android и Windows: задачи, заметки, напоминания, календарь и выбранный персонаж.

## Скачать

[Открыть версии и скачать приложение](https://github.com/Somishh/pomnyu-downloads/releases)

В блоке **Assets** выбранного выпуска:

- **Pomnyu-Android.apk** — приложение для Android 8.0 и новее.
- **Pomnyu-Windows-x64.zip** — приложение для Windows 10 22H2 / Windows 11, x64. Распакуйте ZIP и запустите Pomnyu.exe.
- **INSTALL-RU.txt** — установка, обновление и ограничения.
- **SHA256SUMS.txt** — контрольные суммы файлов.
- **Third-party-licenses.zip** — уведомления и лицензии компонентов.

Аккаунт GitHub для скачивания не нужен. Файлы `Source code (zip)` и `Source code (tar.gz)`, которые GitHub добавляет автоматически, содержат только материалы этой страницы, а не приложение.

Текущая выбранная основа: **Android 0.42.0-dev и Windows 0.8.1-dev**, без совместного планирования. Это тестовые версии. Собственные записи хранятся локально; обмен в домашней сети настраивается отдельно. Дополнительный сервер для личного использования не нужен.

Перед обновлением сохраните внешнюю резервную копию. Если уже установлена Android 0.43, не удаляйте приложение ради старого APK: дождитесь следующей сборки без совместного планирования с большим номером.

## Новые версии и обратная связь

Постоянная ссылка на загрузки — раздел **Releases**. Для уведомлений о выпусках можно включить **Watch → Custom → Releases**. Автоматического обновления внутри приложений пока нет.

Ошибки и пожелания можно оставлять в **Issues**. Укажите версию приложения, модель телефона или версию Windows и шаги воспроизведения. Не публикуйте личные задачи, коды подключения, токены или резервные копии.

В этом репозитории размещаются готовые сборки и инструкции. Исходники и ключи подписи сюда не публикуются.
