# Помню

Личный органайзер на русском языке для Android и Windows: задачи, заметки, напоминания, календарь и выбранный персонаж.

## Скачать

[Открыть версии и скачать приложение](https://github.com/Somishh/pomnyu-downloads/releases)

Текущие версии: **Android 0.46.0-dev и Windows 0.12.0-dev**, без совместного планирования. Это тестовые версии.

В блоке **Assets** выбранного выпуска:

- **Pomnyu-Android.apk** — Android 8.0 и новее. Устанавливайте поверх прежней версии, без удаления приложения.
- **Pomnyu-Windows-x64.zip** — Windows 10 22H2 / Windows 11, x64. Завершите старую версию через значок в трее → «Завершить работу», распакуйте ZIP и запустите Pomnyu.exe.
- **INSTALL-RU.txt** — установка, обновление и ограничения.
- **SHA256SUMS.txt** — контрольные суммы.
- **Third-party-licenses.zip** — лицензии компонентов.

Перед обновлением сохраните внешнюю резервную копию. Android 0.46 (сборка 53) поддерживает подтверждённый переход подписи на Android 13+ и прежнюю подпись на более старых Android. Play Защита может предлагать проверку новой сборки, в том числе при обновлении.

Ворон и сонная Сова заменили Звёздочку; у Лисички серо-голубые глаза. Праздничные темы и отключаемые звуки сохранены. Подсказки со зверьком пока только спланированы.

Собственные записи хранятся локально; обмен в домашней сети настраивается отдельно. Общие данные эксперимента 0.43 / Windows 0.9 не преобразуются в личные автоматически.

Аккаунт GitHub для скачивания не нужен. Source code (zip/tar.gz), добавленные GitHub автоматически, содержат материалы этой страницы, а не исходники приложения.

## Новые версии и обратная связь

Постоянная ссылка — **Releases**. Для уведомлений можно включить **Watch → Custom → Releases**. Автоматического обновления внутри приложений пока нет.

Ошибки и пожелания оставляйте в **Issues**: версия приложения, телефон/Windows и шаги воспроизведения. Не публикуйте личные задачи, коды подключения, токены или резервные копии.

Здесь публикуются готовые приложения и инструкции. Исходники и ключи подписи остаются закрытыми.
